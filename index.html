Blocks

Place: click a block, then the canvas (click same block again to cancel).
Wire: click any port, click the canvas for corners, then click any other port. Drag a corner to reroute. Click a wire, then Delete.
Set how many scenarios, then a pattern on each Input.
Run fills the table. Tick ports in the order you want the columns. The arrows in a header move that column. Click a row to show it on the diagram.
Theoretical solves the speeds directly. Mechanical spins the inputs up through springs, inertia, and ratchet friction, and the table adds torque.
Save writes a JSON file of this diagram, the scenario lists, and the results. Upload reads one back.

Place a block, then click the canvas. Click a placed block or a wire to name it. Click a selected block again to deselect it.
Wires that meet on the same dot share one name, and a wire on an Input or Output uses that block’s name. The table has one column per name. Run sends the equations and the known values to Z3, once per scenario, and fills the other columns. Save writes this diagram and the scenario numbers. Upload reads that file back.
